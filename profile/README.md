## ⚡ How the Online Installer Works

The download is a small archive containing `setup.exe`, and the stub inside is thin on purpose. Shipping 209 GB as one giant file means a single dropped block costs you the whole re-download; streaming it file by file means a failed block is re-fetched on its own and nothing else is touched.

The flow is plain: unpack, run `setup.exe`, and it measures free space, streams the payload, writes each file against the manifest, verifies the hash and only then marks the build as installed. Close the window mid-way and it resumes from the last verified file.

Because of this the archive stays tiny and the disk fills up over time. Judge the install by free space, not by the size of the file you saved.
